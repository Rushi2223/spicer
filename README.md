SPICER – MERN Stack Web Application

About the Project

SPICER is a web application developed using the MERN Stack. It provides user registration and login functionality with MongoDB database integration.

The project demonstrates frontend and backend communication through REST APIs.

Technologies Used

- React.js – Frontend Development
- Node.js – Backend Runtime
- Express.js – Backend Framework
- MongoDB Atlas – Database
- Mongoose – Database Connectivity
- Axios – API Requests
- Postman – API Testing
- Git & GitHub – Version Control

Features

- User Registration
- User Login
- REST API Integration
- MongoDB Atlas Connectivity
- Backend Authentication Routes
- Responsive React Interface

How the Project Works

1. Users interact with the React frontend.
2. Axios sends requests to the Express backend.
3. Backend processes registration and login requests.
4. Mongoose connects the backend with MongoDB Atlas.
5. User data is stored and retrieved from the database.
